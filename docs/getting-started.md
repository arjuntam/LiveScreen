# 安装与连接

## Windows

运行发布页的 x64 EXE，完成安装后打开软件。首次部署请在 Windows 显示设置选择「扩展这些显示器」，保留操作屏为主屏，在软件「设备与连接」手动绑定大屏。

旧版安装器若因卸载器或占用而失败，先关闭安装 / 卸载窗口并备份本机数据。不要自行删除注册表、项目或素材；请提供准确版本和错误提示。

## Mac

打开 DMG，将 LiveScreen 拖入 Applications，弹出安装磁盘，从「应用程序」打开。Mac 当前包适用于 Apple 芯片、macOS 13+。在系统显示器设置关闭镜像，使用扩展显示，再在软件中绑定副屏。

第一次运行时按需允许本地网络访问。若系统拒绝启动或网络连接，请记录提示并检查对应应用权限，不要关闭整个系统防护。

## 手机与远程管理

手机连接可与主机互通的局域网，用相机扫描软件当前二维码，输入旁边的随机配对码。固定使用同一浏览器并保留网站数据可保留信任；更换地址、浏览器或清理网站数据可能需要重新配对。

远程编辑使用控制地址后的 `/admin`，需要远程管理口令。初始口令在主机数据目录的「首次安装口令.txt」中；原生软件菜单可打开该目录。不要把口令或配对码发到公开问题区。远程上传的素材保存在大屏主机。

网页完全打不开时，先在主机浏览器测试显示的完整地址，再检查网络、客户端隔离、同子网和防火墙。地址刷新成功只代表程序已监听，不代表手机一定可达。自动名称读取失败时可填写备用 Wi-Fi 名称。

## 保存、发布与控制

编辑 → 保存场景 / 草稿 → 发布 → 选择场景播放。发布不会改变当前画面。多图可以直接点击任意缩略图跳页；手机保留紧凑的翻页控制。自动轮播可设置手动翻页后暂停，再明确继续。

本机操作优先于远程管理，远程管理优先于手机；操作完成后有短暂保护时间。关闭管理窗口继续播放，从托盘 / Mac 菜单栏或 Dock 找回。暂停输出后可把屏幕交给其他软件；明确「退出软件」停止播放和网页服务。

自启需在正式软件中设置，并以系统实际状态为准。Mac 可能需要系统批准，未公证包的登录项可能不生效。请在自己的设备上完成重启与静默运行验证。

## 0.5.0 预览：导入 PPT / PDF

在“项目与场景”选择目标项目，点“导入 PPT / PDF”。选择文件，等待上传和转换，检查缩略图，选择需要的页面并填写场景名称，点“创建多图场景”。导入后请“保存场景 → 发布项目”，再在播放页选择该场景。默认手动翻页、完整显示；可改为自动轮播。

PDF 不需要额外办公软件。PPT/PPTX 的转换发生在大屏主机：Windows 可用 Microsoft PowerPoint，Windows / Mac 可用 LibreOffice。只有远程上传电脑安装 Office 并不足够。未发现转换工具时，软件提供 PDF 导入；可在制作 PPT 的电脑先导出 PDF。软件不捆绑整套 Office，也不会自动安装转换程序。

不支持密码保护文稿、PPTM 宏演示格式、动画、内嵌视频/音频和交互播放。PPT 的复杂字体和版式可能存在差异，请先检查预览；需要更新时重新导入，已导入场景不会跟随原文稿自动改变。

单个文件最多 128 MB、200 页，每个场景最多选择 50 页。取消或失败不会改变正式播放；未确认的转换缓存 30 分钟后清理，已确认图片保存在大屏主机当前素材目录下。导入完成后的播放不需要继续运行转换工具。

## 非 16:9 与异形屏

只要操作系统将屏幕识别为可用的独立扩展显示器，即可绑定；不限制为 1920×1080 或 16:9。软件按该屏幕的矩形画布输出；“完整显示”可能留边，“填满画面”可能裁切，不会主动按比例拉伸内容。

L 形、圆形、缺角和多块不规则拼接屏的物理映射由显卡或 LED 控制器完成。软件不自动生成对应遮罩。极端比例下的字号、二维码可扫描距离与实际映射效果仍须现场检查。

## 0.6.0 候选功能

### 视频声音

编辑视频场景时勾选“播放视频声音”，保存场景并发布，再选择播放。旧场景默认静音，编辑预览始终静音。声音使用大屏主机的系统音频输出；是否走 HDMI、扬声器或声卡由操作系统设置决定。切走场景、暂停大屏输出或退出软件会停止视频声音。PPT 内嵌多媒体仍不导入。

### 单屏远程运行

在“设备与连接 / 连接与设置”选择“单屏远程”，明确绑定外接主屏。双屏模式继续保护运营主屏，内置屏不可选；换成陌生显示器后仍需确认。登录后的图形会话、合盖不休眠与输出连接由系统配置。

远程管理员可查看显示器、绑定输出、暂停 / 恢复及配置登录自启。“启动后显示”可选配对指南、立即播放默认背景或立即恢复上次场景。

远程页面设置内的“退出软件”会在确认后关闭整个主机软件和网页服务。收到受理状态后需要在主机重新启动；网页无法唤醒已经退出的软件。普通临时让出屏幕请用“暂停大屏输出”，以保留网页服务。

管理窗口 X 只隐藏窗口。单屏模式下通过托盘或再次打开 LiveScreen 找回管理时，会先暂停大屏输出。设置内显示已注册的本机应急快捷键；默认尝试 Ctrl / Command + Alt + Shift + L，冲突时尝试 F12，两个都不可用时会明确提示。快捷键用于暂停输出并打开管理。Windows 全屏下的实际按键行为待实机验收。

### 迁移素材目录

本机软件可选择空文件夹；远程管理要填写**大屏主机上的绝对目录**，例如 `D:\LiveScreenMedia`。先检查，再点“复制并迁移素材”。过程为复制、逐文件 SHA-256 校验、切换设置；迁移期间暂停上传、保存与导入确认，现有播放继续读取原位置。成功后旧文件保留，新上传及 PPT / PDF 确认图片使用新目录。

首版面向本机磁盘，不承诺 NAS、网络盘或任意外接文件系统。原目录失联时不会自动创建替代素材库；请恢复原磁盘连接。目标必须存在、可写且为空，复制后至少保留 1 GB 空闲空间。项目索引、口令与绑定配置仍留在原应用数据目录。
