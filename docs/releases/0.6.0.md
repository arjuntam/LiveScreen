# LiveScreen 0.6.0 · 单屏远程与场景声音（候选版）

- 单屏 / 双屏并行支持；单屏模式可明确绑定外接主屏，保留陌生屏幕暂停保护。
- 远程管理员可绑定、暂停 / 恢复输出、配置自启和确认后退出；手机继续辅助，本机优先。
- 本机应急快捷键、再次打开时现场接管；管理窗口关闭继续播放。
- 启动可选指南、默认背景或上次场景。
- 素材目录先复制与校验，再切换；原素材保留，目录失联明确反馈。
- 视频场景可勾选播放声音；旧场景默认静音，编辑预览保持静音。
- 修复 PDF 源图超过 1600 万像素时选页预览变白；仍按有限输出尺寸生成静态页面。
- 保留中英文运行时资源，裁剪重复 PDF 构建文件；字体、PDF 解码与媒体运行依赖保留。

候选版仍需 Windows 实机验收。当前不包含 AirPlay、采集卡、多路屏幕独立输出或 Tauri 迁移。PPT 动画与内嵌媒体不导入。
