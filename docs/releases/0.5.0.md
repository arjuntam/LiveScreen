LiveScreen 0.5.0 功能预览：PPT / PDF 静态导入与非 16:9 预览。

- 新增“导入 PPT / PDF”，逐页预览、选择 1–50 页后创建多图场景，默认手动翻页、完整显示。
- PDF 无需 Office；PPT/PPTX 依赖大屏主机已安装的 Windows PowerPoint 或 LibreOffice，不捆绑办公软件。
- 远程上传、后台转换、取消、失败和确认导入不直接改变正式播放；保存、发布后再选择场景。
- 非 16:9 矩形扩展屏按系统尺寸输出；编辑预览跟随已绑定比例，配对指南完整适配超宽/竖屏画布。
- 不包含 PPT 动画、视频、音频或交互；请检查字体和版式的转换预览。物理异形屏仍由 LED 控制器映射。

本次为预览版。PDF、Mac LibreOffice 转换和模拟比例窗口已验证；Windows PowerPoint 自动化、真实 LED 异形映射、字体还原和安装升级仍需在部署设备复验。Windows / Mac 的自动测试和安装包校验通过后才发布文件。安装包未取得 Windows 商业签名 / Apple 公证；Mac 为 Apple 芯片版本，macOS 13+。
